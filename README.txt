POUR OUVRIR LE SITE
Double-cliquez sur index.html.

VIDÉOS
Une zone vidéo est déjà prévue.
Pour utiliser une vidéo MP4 :
1. Placez votre fichier dans assets/, par exemple assets/soiree.mp4
2. Dans index.html, cherchez :
   <source src="" type="video/mp4">
3. Remplacez par :
   <source src="assets/soiree.mp4" type="video/mp4">
